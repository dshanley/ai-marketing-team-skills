# Decision categories register

One row per category of decision you keep facing, not per incident. Review it at the team's
AI practice meeting and add the rule whenever the same call comes up twice.

| Category | Door (two-way or one-way) | Who decides | The rule | Added / owner |
|---|---|---|---|---|
| Example: subject line variants | Two-way | Agent | Test two. Keep the one that follows the voice rules. Log the choice. | |
| Example: spend above the approved cap | One-way | Campaign owner | Agent stops and sends problem, options, recommendation. | |
| | | | | |

## Reading the table

- **Two-way door:** cheap to reverse. Decided inside the boundary. No escalation.
- **One-way door:** expensive or impossible to reverse. Comes up as completed staff work.
- **Unsure which door?** Treat it as one-way for a month, then reclassify with what you learned.
